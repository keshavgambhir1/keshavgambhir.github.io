# Keshav Gambhir Portfolio

Plain HTML, CSS and JS. No build step, no framework.

## Files
- `index.html` : page content (resume text lives here)
- `style.css` : black/yellow theme, dark and light mode
- `script.js` : work-sample list (edit the `works` array), theme toggle
- `photo.jpg` : ADD YOUR PHOTO HERE (square-ish crop works best). Until then a "KG" monogram shows.

## Add your links
Open `script.js`, edit the `works` array at the top: set `title`, `desc`, and paste the link in `url`.

## Preview locally
Double-click `index.html`.

## Free hosting (pick one)
1. **GitHub Pages**: create a repo, upload these files, Settings > Pages > deploy from main branch. URL: `username.github.io/repo`
2. **Netlify**: go to app.netlify.com/drop and drag the folder in. Live in seconds. You can rename the subdomain.
3. **Vercel** (you already use it): import the GitHub repo, or run `vercel` in this folder.
4. **Cloudflare Pages**: connect the GitHub repo, no build command, output directory `/`.
